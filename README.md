# Пингборд

[![Проверки и сборка](https://github.com/DenisDudyrew/pingboard/actions/workflows/desktop.yml/badge.svg?branch=main)](https://github.com/DenisDudyrew/pingboard/actions/workflows/desktop.yml)

Пингборд — настольная доска со стикерами для рабочих задач и личных планов. Задачи и настройки хранятся локально в SQLite. Для работы с доской не нужен аккаунт.

## Скачать и установить

1. Откройте [GitHub Releases](https://github.com/DenisDudyrew/pingboard/releases) и скачайте файл `Pingboard-<версия>-macOS-Apple-Silicon.dmg` из раздела Assets.
2. Откройте DMG и перетащите Pingboard в «Программы».
3. Запустите Pingboard из Finder. При настройке первого напоминания разрешите уведомления macOS.

Установщик предназначен для Mac с Apple Silicon.

## Что умеет Пингборд

- Свободная доска заполняет окно под компактной шапкой. Палитра находится слева, масштаб и «В начало» — справа внизу, выбор фона — слева внизу. Поиск и фильтры открываются по кнопке с лупой. Перетащите цвет из палитры на доску или в колонку канбана, затем дважды щёлкните по стикеру или нажмите правой кнопкой. Над углом стикера по дуге появятся квадратные кнопки редактирования, завершения и уничтожения. На доске карандаш включает редактирование прямо в стикере. «Детали» открывают полный редактор с настройками, включая цвет пина. Крестик и галочка находятся сверху.
- Области группируют стикеры на свободной доске. Перетащите кнопку области из левой палитры на полотно или нажмите её, чтобы поставить область в центре. Нажмите на заголовок, чтобы изменить название, описание, цвет и размеры. Перетаскивание области переносит стикеры, центр которых находится внутри неё. В пересечении областей стикер относится к верхней. При удалении области стикеры остаются на доске.
- Два пальца на трекпаде перемещают полотно, щипок меняет масштаб. Выберите результат поиска, чтобы перейти к стикеру.
- В меню «Данные» можно сохранить JSON-копию задач и настроек или восстановиться из неё. На Mac обе копии, включая копию перед восстановлением, сохраняются в «Загрузки».
- Пять фонов для свободной доски: сетка, облако, графит, линии и мята.
- Карточки с заметками, цветными метками и чек-листами.
- Отдельный канбан с перетаскиванием между колонками «В планах», «В работе» и «Готово».
- Поиск по названию, заметке и меткам, фильтры «Работа» и «Личное».
- Экран «Сегодня» с просроченными задачами, сроками на сегодня и ближайшей будущей задачей.
- Системные напоминания macOS по срокам задач. При переносе срока приложение обновляет напоминание, при завершении или удалении отменяет его.

- Действие «Уничтожить» удаляет стикер с одним из семи случайных эффектов: огонь, пробоины, электрический разряд, ветер, разрез, пиксели или складывание. Эффекты длятся 1,55–1,8 секунды. Два одинаковых эффекта подряд не выпадают. Системная настройка уменьшения движения отключает анимацию.

## Горячие клавиши на доске

| Клавиши | Действие |
| --- | --- |
| ⌘⇧N | Создать стикер |
| ⌘⇧A | Создать область |
| ⌘F | Открыть поиск |
| ⌘+ / ⌘− | Изменить масштаб |
| ⌘0 | Вернуть полотно в начало и масштаб 100% |
| Стрелки | Сдвинуть стикер или область в фокусе |
| Enter / Esc | Открыть действие в фокусе или закрыть редактор |

Список также доступен по кнопке клавиатуры на доске.

## Разработка

Интерфейс использует React, TypeScript и Vite. Настольное окно и доступ к SQLite реализованы на Tauri и Rust, напоминания — на Swift.

На Mac понадобятся Node.js 24, Rust с Cargo и инструменты командной строки Xcode.

```sh
npm ci
cargo install tauri-cli --version '^2' --locked
npm start
```

| Команда | Назначение |
| --- | --- |
| `npm test` | Собрать интерфейс и проверить логику доски, напоминаний и SQLite |
| `npm run test:ui` | Запустить браузерный тест интерфейса после `npx playwright-core install chromium` |
| `npm run test:macos` | Проверить системные напоминания в тестовом приложении с разрешёнными уведомлениями |
| `npm run build` | Собрать приложение и DMG в `src-tauri/target/release/bundle/` |

## CI/CD и выпуск версий

[GitHub Actions](https://github.com/DenisDudyrew/pingboard/actions) запускает тесты и собирает DMG для pull request и изменений в `main`. Для выпуска обновите версию в `package.json`, `package-lock.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`. После успешной сборки из `main` GitHub публикует новую версию с установщиком и `SHA256SUMS.txt`. Повторная сборка версии доступна в артефактах Actions.
