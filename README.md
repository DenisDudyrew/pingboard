# Пингборд

Локальная доска для рабочих задач и личных планов. Перемещайте карточки между колонками, назначайте сроки и открывайте «Сегодня» для просмотра ближайших задач. Добавляйте цветные метки через запятую и ищите задачи по названию, заметке или метке. Чек-лист хранит отдельные шаги и показывает прогресс на карточке.

## Установка на macOS

Целевой формат выпуска — образ DMG с приложением Pingboard.app. После сборки откройте DMG, перетащите Pingboard в «Программы» и запустите его из Finder. Задачи и настройки хранятся в SQLite в каталоге данных приложения. При первом планировании напоминания разрешите уведомления в macOS.

## Разработка и сборка

На Mac понадобятся инструменты командной строки Xcode, Node.js 24 или новее, Rust с Cargo и Tauri CLI 2 (`cargo install tauri-cli --version "^2" --locked`). В корне проекта выполните `npm install`.

- `npm start` собирает интерфейс и открывает окно Tauri для разработки.
- `npm run build` собирает приложение и установочный образ. Результаты находятся в `src-tauri/target/release/bundle/macos/` и `src-tauri/target/release/bundle/dmg/`.
- `npm test` собирает интерфейс и проверяет правила доски, SQLite и вызовы нативного моста.
- `npm run test:ui` проверяет интерфейс в Chromium. Перед первым запуском выполните `npx playwright-core install chromium`.
- `npm run test:macos` проверяет системные напоминания в отдельном тестовом приложении. Для проверки доставки ему требуется разрешение на уведомления.

Для приёмки настольного выпуска установите приложение из собранного DMG, создайте задачу и выберите фильтр. Завершите приложение через ⌘Q и проверьте доставку напоминания. После повторного запуска проверьте карточку и фильтр. Отдельно проверьте перенос срока и завершение задачи до срока.

## Релизы

GitHub Actions собирает DMG для Mac с Apple Silicon при обновлении main. Для выпуска новой версии обновите версию в package.json, package-lock.json, src-tauri/Cargo.toml и src-tauri/tauri.conf.json. После тестов и проверки образа установщик и SHA256SUMS.txt публикуются в [GitHub Releases](https://github.com/DenisDudyrew/pingboard/releases). Повторная сборка той же версии доступна в артефактах Actions.
